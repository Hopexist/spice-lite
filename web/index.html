What it does

Checked against ngspice

824 Python tests. Every bundled example has a committed ngspice 41 reference. Linear .op and .dc agree to 1e-9 relative, .ac to 1e-6, and each transient to a tolerance written next to its test.

DC

.op operating points and .dc sweeps of any V or I source.

AC

.ac dec | oct | lin: complex MNA, magnitude in dB and phase in degrees.

Transient

Backward Euler or trapezoidal, PULSE and SIN sources, .ic with uic.

Adaptive steps

Local-error control places 191 steps where a fixed step needs 5,000 and is still less accurate (stiff_adaptive).

Nonlinear

Diodes and level-1 MOSFETs with overlap capacitances, solved by Newton-Raphson with junction limiting and gmin stepping.

Controlled sources

E, G, F and H. An op-amp is an E with a gain of 1e6.

Runs in WebAssembly

Pyodide (Python 3.14) in a Web Worker, so the page never freezes. About 24 MB on the first visit, cached after.

Supported elements

One sheet per element the netlist parser accepts. Values in SI units; anything the parser rejects is an error with its line number.

About this project

spice-lite is a SPICE-style circuit simulator written from scratch in Python, as a learning and portfolio project by an electrical-engineering student. It is not a replacement for ngspice: the README lists what it does not model.

How it is verified

824 Python tests, 65 of which compare against ngspice 41, each with a tolerance written next to it. Where a closed form exists the answer is also checked against it (RC step response, filter corners, the exact diode solution), and convergence-order tests check that halving the step halves backward Euler's error and quarters trapezoidal's. The "ngspice reference" box on a plot overlays precomputed ngspice curves; it is not a live ngspice run.

Nothing you type leaves your browser

The simulator is Python compiled to WebAssembly (Pyodide), running in a Web Worker on your own machine, so your netlist is never uploaded. A share link keeps the circuit after the # in its address, which browsers do not send to servers. The page does download static files: its own assets, and Python, NumPy and SciPy from the jsDelivr CDN (about 24 MB on the first visit).
